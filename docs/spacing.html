Spacing system

The site’s spacing system: one scale, a handful of named spacings with a clear order (closer means more related), and one line-height per type role. Everything below is drawn with the live tokens. The rules are in spacing.md.

The scale

Eleven steps on a 4px base. The old scale’s 20, 40, 56, 72, 88 and 104 are gone; each moved to its nearest step.

Named spacings, in order of relation

Each spacing has a job, and every value is measured ink to ink (leading trimmed). The order is the point: 8 < 16 < 24 < 32 < 64–128, so the space inside a group is always clearly smaller than the space between groups.
